**Notes:**

### In-game bindings

| Action | Key |
|--------|-----|
| Move forward / back | E / D |
| Strafe left / right | S / F |
| Jump | Space (left thumb) |
| Toggle autorun | `-` (left thumb) |
| Spare | `=` (left thumb) |
| Main bar | Mouse 4, Mouse 5, R, W, A, G, T, C, V, X, Q, Z |
| Bottom-left bar | Shift + the main bar keys |
| Bottom-right bar | Ctrl + the main bar keys |
| Right bar | 1-5, for mount, hearthstone, food, water and bandages |
| Self-cast | Alt + key, left unbound |

Put each character's most-used abilities on the main bar, nearest keys first,
because that is the bar that swaps with stances, forms and stealth. Leave
"Character Specific Key Bindings" off so every character shares the same keys.

## Layer 10: Game Controls

Hold any `L10` key on the game layer. Everything not listed is transparent.

| Key | Action |
|-----|--------|
| Number row | F1-F12, in the same positions as Layer 2 |
| Q | Mac profile |
| W | Windows profile |
| E | Game profile for the Windows PC |
| R | Game profile for streaming from the Mac |

Layer 9 sits above Layers 2 and 3, so holding their keys would still send its
number row. Layer 10 exists so F-keys and profile switches work from the game.

## Quick Profile Switching

Access **Layer 3** (hold key in top-right of left number row), then:

| Key | Profile | Layer | BT Slot |
|-----|---------|-------|---------|
| 1   | Mac     | 0     | 0       |
| 2   | Windows | 8     | 1       |
| 3   | Game (Windows PC) | 9 | 1 |
| R   | Game (streaming from Mac) | 9 | 0 |

From the game layer, use **Layer 10** instead (see above).
